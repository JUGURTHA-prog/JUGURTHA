# CarRent - Vehicle Rental Website

A modern, responsive car rental website built with HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Vehicle Fleet**: Browse and view different vehicle categories (Economy, Sedan, SUV, Luxury)
- **Online Booking System**: Easy-to-use booking form with date validation
- **Smooth Navigation**: Sticky navigation bar with smooth scrolling
- **Booking History**: Bookings are saved to browser's localStorage
- **Modern UI**: Gradient backgrounds and smooth animations

## Project Structure

```
car-rental-website/
├── index.html       # Main HTML file
├── styles.css       # Styling
├── script.js        # JavaScript functionality

```

## Sections

1. **Navigation Bar**: Quick access to all sections
2. **Hero Section**: Eye-catching welcome section
3. **Fleet**: Display of available vehicles with prices and features
4. **Booking System**: Form to book vehicles with pickup and return dates
5. **About**: Information about the service
6. **Contact**: Contact information
7. **Footer**: Copyright information

## How to Use

1. Open `index.html` in a web browser
2. Browse available vehicles in the "Our Fleet" section
3. Fill out the booking form with your details
4. Select your preferred vehicle, pickup and return dates
5. Submit your booking

## Features Implemented

- Date validation (return date must be after pickup date)
- Minimum date restriction (can't book in the past)
- Booking confirmation alert
- Booking history saved to localStorage
- Responsive grid layout
- Smooth animations and transitions
- Form validation
